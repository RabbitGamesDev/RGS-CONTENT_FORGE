01 // ¿PARA QUÉ SIRVE ESTA HERRAMIENTA?

RGS Content Forge es un motor multimodal diseñado para desarrolladores e Indie Hackers. Transforma capturas de pantalla, archivos de código o demos en video en copys adaptados para redes sociales, manteniendo una voz orgánica, devlog y libre de clichés corporativos.

02 // ARQUITECTURA TÉCNICA (CÓMO FUNCIONA)

  • Procesamiento Inteligente: Archivos pequeños (<20MB) se procesan al vuelo en Base64. Archivos grandes (videos pesados) utilizan de forma transparente la Google Files API con fallback automático entre modelos Gemini.
  • Zero-Backend: La aplicación corre 100% en el cliente (Browser), comunicándose directamente con la API de Google sin intermediarios ni servidores de terceros.

03 // GUÍA RÁPIDA DE USO

  1. Ingresa tu API Key: Consigue tu clave gratuita en Google AI Studio.
  2. Adjunta Contexto: Sube una imagen/video de tu avance o escribe brevemente qué lograste.
  3. Selecciona Plataformas y Tono: Marca las redes donde publicarás y elige el estilo que mejor encaje.
  4. Refina e Repite: Usa la opción [ REFINE ] dentro de cada tarjeta para hacer ajustes finos sin volver a procesar todo.

04 // POLÍTICAS Y PRIVACIDAD COMPLETA

En RGS Labs la privacidad y la seguridad del código son prioridad:

  • Almacenamiento Local: Tu GEMINI_API_KEY se guarda exclusivamente en el localStorage de tu navegador. Nadie más tiene acceso a ella.
  • Manejo de Archivos: Los archivos subidos no se almacenan en ninguna base de datos de RGS Labs. Se envían directamente a los servidores de procesamiento de Google y se eliminan temporalmente según las políticas de retención de la Files API.
